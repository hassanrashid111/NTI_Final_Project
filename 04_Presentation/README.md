## 🚀 How to Run the Presentation (طريقة التشغيل)

1. **Option A (Direct File Launch)**:
   - Double-click [`index.html`](file:///f:/NTI/Demand%20Forecasting%20System%20Backup/04_Presentation/index.html) in your file browser or open it directly in Google Chrome / Edge.

2. **Option B (FastAPI Web App Integration)**:
   - Run `python -m uvicorn backend.app:app --port 8000` in `02_App`.
   - Access the presentation at `http://localhost:8000/presentation/` (or via the Guide page link).
