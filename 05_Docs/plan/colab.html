⚡ Setup Guide — خطوة بخطوة

1
Clone the Repository
▼

أول خطوة — انسخ الريبو من GitHub على Colab

# Clone the repository !git clone https://github.com/hassanrashid111/NTI_Final_Project.git %cd NTI_Final_Project # Check the structure !ls -la
💡 Tip
لو الريبو private, هتحتاج Personal Access Token من GitHub.
2
Install Dependencies
▼
# Install all required packages !pip install -r requirements.txt # Or install individually !pip install pandas numpy scikit-learn !pip install catboost lightgbm !pip install pytorch-forecasting pytorch-lightning !pip install streamlit plotly seaborn !pip install polars # For handling large data
3
Download Dataset from Kaggle
▼

Option A: Using Kaggle API (Recommended)

# Step 1: Install Kaggle API !pip install kaggle # Step 2: Upload your kaggle.json from google.colab import files uploaded = files.upload() # Upload kaggle.json file # Step 3: Setup credentials !mkdir -p ~/.kaggle !cp kaggle.json ~/.kaggle/ !chmod 600 ~/.kaggle/kaggle.json # Step 4: Download the dataset !kaggle datasets download -d ruiyuanfan/corporacin-favorita-grocery-sales-forecasting # Step 5: Extract to data/raw/ !mkdir -p data/raw !unzip -q corporacin-favorita-grocery-sales-forecasting.zip -d data/raw/ # Step 6: Verify !ls -la data/raw/

Option B: Manual Upload

# Download from Kaggle website and upload to Colab from google.colab import files uploaded = files.upload() # Upload the zip file # Extract !mkdir -p data/raw !unzip -q *.zip -d data/raw/
⚠️ How to get kaggle.json
  1. روح على kaggle.com/settings
  2. في قسم API اضغط "Create New Token"
  3. هينزل ملف kaggle.json — ارفعه على Colab
4
Mount Google Drive (Persistent Storage)
▼

Colab بيمسح كل شيء لما الـ session ينتهي. عشان كده لازم نخزن على Google Drive.

# Mount Google Drive from google.colab import drive drive.mount('/content/drive') # Create project folder on Drive !mkdir -p /content/drive/MyDrive/NTI_Project # Save important files to Drive !cp -r models/ /content/drive/MyDrive/NTI_Project/models/ !cp -r data/processed/ /content/drive/MyDrive/NTI_Project/data/ # Load from Drive (in new session) !cp -r /content/drive/MyDrive/NTI_Project/models/ models/ !cp -r /content/drive/MyDrive/NTI_Project/data/ data/
5
Enable GPU (for TFT Training)
▼

How to Enable

  1. اضغط Runtime في القائمة العلوية
  2. اختر Change runtime type
  3. في Hardware accelerator اختر GPU (T4)
  4. اضغط Save

Verify GPU

# Check if GPU is available !nvidia-smi # Check PyTorch GPU import torch print(torch.cuda.is_available()) print(torch.cuda.get_device_name(0))
⚠️ GPU Quota
Colab المجاني عنده حد للـ GPU usage. لو انتهى، استنى 24 ساعة أو استخدم Colab Pro.
6
Push to GitHub (Save Progress)
▼
# Configure Git !git config --global user.email "your-email@example.com" !git config --global user.name "Your Name" # Check status !git status # Add and commit !git add . !git commit -m "Phase X: Description of changes" # Push to GitHub !git push origin main
💡 Authentication
استخدم Personal Access Token بدل password. روح على GitHub Settings → Tokens واعمل token جديد.

💡 Best Practices

نصائح مهمة للشغل على Colab

💾

Save Often

خزّن الموديلات والداتا على Google Drive بعد كل خطوة مهمة. Colab ممكن ينقطع في أي وقت.

🧠

Memory Management

استخدم gc.collect() و del لتحرير الذاكرة. الداتا كبيرة (~5 GB).

import gc del large_dataframe gc.collect()
📊

Data Sampling

ابدأ بـ sample صغير (1-5%) للتطوير والتجريب. استخدم الكل للتدريب النهائي فقط.

# Use sample for dev df_sample = df.sample(frac=0.05)
⚡

Use Polars

Polars أسرع من Pandas بكتير مع الداتا الكبيرة. استخدمه للـ data loading.

import polars as pl df = pl.read_csv("data/raw/train.csv")
📁

Parquet Format

خزّن الداتا المعالجة كـ Parquet مش CSV. أسرع وأصغر في الحجم.

df.to_parquet("data/processed/clean.parquet")
🔄

Git Commits

اعمل commit بعد كل مرحلة. استخدم commit messages واضحة.

"Phase 3: Complete EDA analysis" "Phase 5: Add lag features"
