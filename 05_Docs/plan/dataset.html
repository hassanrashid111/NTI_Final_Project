📖 About the Dataset

Corporación Favorita هي أكبر سلسلة سوبر ماركت في الإكوادور. الداتا سيت بيحتوي على بيانات مبيعات يومية من يناير 2013 حتى أغسطس 2017 لحوالي 4,000+ منتج في 54 فرع مختلف. الهدف هو التنبؤ بعدد الوحدات المباعة (unit_sales) لكل منتج في كل فرع.

💡 Key Insight
الإكوادور دولة تعتمد على البترول — لذلك أسعار البترول تؤثر مباشرة على القوة الشرائية للمواطنين.

🎯 Target Variable

unit_sales

عدد الوحدات المباعة يومياً لكل منتج في كل متجر

  • Type: float (continuous)
  • القيم السالبة تمثل مرتجعات (returns)
  • سنعمل clip عند 0 أو log transform
  • التوزيع: Right-skewed (معظم القيم صغيرة)
