تفاصيل كل متطلب وكيف نحققه بالضبط

1
Real-world Problem
✓ Done ▼

المشكلة

التنبؤ بالطلب على المنتجات في سلاسل محلات Corporación Favorita في الإكوادور. هي أكبر سلسلة سوبر ماركت في الإكوادور مع 54 فرع وآلاف المنتجات.

القيمة العملية

  • تقليل الفاقد من المنتجات (خصوصاً القابلة للتلف)
  • تحسين إدارة المخزون وتقليل التكاليف
  • تجنب نفاد المخزون (Stockouts) وزيادة رضا العملاء
  • تحسين عمليات سلسلة التوريد
✅ Verdict
المشروع يحل مشكلة حقيقية في قطاع التجزئة (Retail) وهو من أكثر تطبيقات ML استخداماً في الصناعة.

Full ML Pipeline
✓ Done ▼

3
Suitable ML Models (with Justification)
✓ Done ▼

🌲 CatBoost

لماذا؟ ممتاز مع Categorical Features بدون encoding يدوي. مقاوم للـ Overfitting. يدعم GPU training.

Categorical GPU Robust

⚡ LightGBM

لماذا؟ الأسرع في Gradient Boosting. كفاءة عالية مع الداتا الكبيرة (~125M rows). Low memory usage.

Fast Scalable Efficient

🧠 TFT

لماذا؟ مصمم خصيصاً للـ Time Series. يدعم Multi-horizon forecasting. Attention mechanism لفهم أهم Features.

Deep Learning Attention Multi-horizon
💡 Baseline Model
نبدأ بـ Linear Regression كـ baseline للمقارنة — ده بيوضح للمحاضر إننا فاهمين أهمية benchmarking.
